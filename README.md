# Northstar student registration

A responsive student registration website built with HTML, CSS, and vanilla JavaScript. No installation or build tools required.

## Open the website

Open `index.html` in any modern browser. Open this folder in VS Code to edit the project.

## Features

- Three steps: personal details, academic interests, and review.
- Required fields, email and phone validation, and prevention of future birth dates.
- Editable details before confirmation and a downloadable plain-text receipt.
- Responsive layouts, keyboard controls, labeled inputs, and accessible progress indicators.
- Safe rendering of entered text without HTML injection.

## Files

- `index.html`: page structure and registration form.
- `styles.css`: responsive styling and decorative CSS artwork.
- `script.js`: validation, step navigation, review, and receipt download.

This is a front-end demonstration. It does not send email, save student records, or submit applications to a real institution. Details exist only in the current page's memory until downloaded; reloading clears the form state. Connect a secure backend before using it for real admissions.

Google Fonts is optional and requires internet access. System sans-serif fonts are used when unavailable. All other functionality works offline.
